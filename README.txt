ZEVORIA REAL STORE FRONT-END
Open index.html in Chrome to preview.

This version is designed to feel like a real storefront rather than an AI mockup:
- real navigation and anchors
- working product filters
- working search
- persistent cart using localStorage
- quantity/remove controls
- wishlist interaction
- account and checkout dialogs
- newsletter/contact links
- responsive mobile navigation

For a production store, connect the checkout form to your backend and Razorpay/other payment gateway, add real authentication, database, stock, shipping, webhook verification and admin controls. Never place payment secrets in this front-end.
